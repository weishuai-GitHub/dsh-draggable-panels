# 原生工作区功能边界

本次 0.6.0 是组件化重构，不宣称与全部原生扩展完全等价。

## 保留的能力

- 原生左侧外壳、设置/导航与完整原生界面恢复。
- 工作区默认名称本地化、文件夹当前组高亮、标题六点拖拽标识。
- 工作区/工作区树/平铺视图、更新/手动顺序展示、归档筛选、分页与全文搜索。
- 按指定 workspaceId 新建会话；native picker 添加工作区；重命名、确认移除注册。
- 会话重命名、置顶、分叉、归档/恢复及对应菜单。
- 单一文件面板、只读文本分页预览。

## 不应宣称已补齐的部分

- 原生快捷键提示及全部键盘命令路由。
- 原生工作区和会话拖动排序的全部 UI；“手动排序”当前使用已有成员顺序，不等于已实现全部原生行拖动交互。
- 原生第三方会话行装饰、悬停卡及菜单扩展 Slot 的完整透传。
- 运行中归档的自动停止确认流程：当前保留 Host 安全拒绝，不自动 stopActivity。
- 原生 Office/二进制文件预览、终端等右栏插件的自动转换。可恢复原生界面，或由对应插件适配新组件协议。

新增的开放组件注册接口是独立且明确的扩展协议，不意味着现存任意插件安装后会自动转换为可拖拽组件。
